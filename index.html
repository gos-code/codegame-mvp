🚀 CodeGame 시작하기

CodeGame은 즉시 실행 가능한 코드 자산을 거래하는 국내 최초 플랫폼이에요. 자동화 스크립트부터 기능 모듈까지, 완성된 코드를 사고팔아요.

💡CodeGame의 핵심 철학: 코드 조각이 아닌 완성된 기능을 거래해요. 구매 즉시 실행 가능해야 하며, 환경설정 가이드가 포함되어야 해요.

5분 만에 시작하기

1

회원가입

이메일 또는 카카오/구글 소셜 로그인으로 30초 만에 가입할 수 있어요.

2

마켓 둘러보기

카테고리나 검색으로 원하는 코드 자산을 찾아보세요.

3

구매 또는 판매

구매자라면 결제 후 즉시 다운로드, 판매자라면 코드를 업로드하고 검수를 기다려요.

4

실행 및 리뷰

구매한 코드를 실행해보고 별점과 리뷰를 남겨주세요.

💰 판매자 가이드

잘 팔리는 코드 자산을 만들기 위한 핵심 원칙이에요.

🔥인기 판매자들의 공통점: 구체적인 문제를 해결하고, README가 친절하며, 빠른 업데이트를 해요.

잘 팔리는 코드의 조건

  • 즉시 실행 가능 — pip install 한 줄로 환경 세팅 완료
  • 명확한 문제 해결 — "스마트스토어 주문 자동화"처럼 구체적
  • 친절한 README — 설치법, 사용법, 주의사항 포함
  • 에러 처리 포함 — 예외상황에도 안 멈추는 코드
  • 업데이트 제공 — API 변경 시 빠른 패치
# ✅ 좋은 예 — 명확한 함수명과 에러처리 def process_order(order_id: str) -> dict: try: order = fetch_order(order_id) result = update_tracking(order) return {"status": "success", "data": result} except Exception as e: logger.error(f"주문 처리 실패: {e}") return {"status": "error", "message": str(e)}

수익 정산 안내

  • 판매 수수료: 20% (플랫폼 운영비)
  • 판매자 수익: 80% 지급
  • 정산 주기: 매월 말 (최소 출금액 10,000원)
  • 정산 방법: 계좌이체

🛒 구매자 가이드

CodeGame에서 구매한 코드는 영구 소유예요. 업데이트가 있으면 무료로 받을 수 있어요.

구매 후 사용 방법

1

다운로드

결제 완료 후 마이페이지에서 즉시 다운로드 가능해요.

2

환경 설정

README를 먼저 읽어보세요. requirements.txt로 한 번에 설치 가능해요.

3

실행

config.json에 API 키 등을 입력하고 실행하면 돼요.

환불 정책

  • 구매 후 24시간 이내 — 전액 환불 가능
  • 코드가 설명과 다를 경우 — 전액 환불
  • 실행 오류 발생 시 — 판매자 수정 요청 또는 환불
  • 단순 변심 — 환불 불가 (미리보기 활용 권장)

📝 잘 팔리는 코드 작성 팁

실제 판매 데이터를 기반으로 분석한 핵심 팁이에요.

코드 품질 체크리스트

  • 함수/변수명은 영어로, 주석은 한국어로
  • requirements.txt 또는 package.json 포함
  • config 파일 분리 (하드코딩 금지)
  • 로그 출력 포함 (실행 중 상태 확인 가능)
  • 예외처리 필수 (try/except, try/catch)
  • 테스트 코드 또는 샘플 데이터 포함
# config.json — 하드코딩 대신 설정 파일 분리 { "api_key": "여기에_API키_입력", "store_id": "여기에_스토어ID", "interval_seconds": 30, "max_retries": 3 }

⚖️ 라이선스 안내
